# DLD Verilog Programs

This folder maps the Verilog programs to the ECE2002 Digital Logic Design syllabus experiment list.

| Folder | Syllabus experiment |
| --- | --- |
| `exp01_adders_subtractors` | Design and implementation of half adder, full adder, half subtractor, full subtractor |
| `exp02_code_converters` | BCD to Gray, Gray to BCD, BCD to Excess-3 |
| `exp03_mux_demux` | MUX/DEMUX using basic gates and Boolean function implementation using MUX |
| `exp04_datapath_elements` | 4-bit adder and 2-bit multiplier |
| `exp05_flipflops` | Flip-flop verification and construction of a flip-flop/latch using gates |
| `exp06_mod_counters` | MOD counter design and implementation |
| `exp07_sim_adders_subtractors` | Simulation of adders and subtractors |
| `exp08_encoder_decoder` | Encoder and decoder simulation |
| `exp09_nbit_adder_multiplier_converters` | N-bit adder, multiplier, and code converters |
| `exp10_shift_registers` | Shift register simulation |
| `exp11_counters` | Different counter simulations |

Each experiment folder contains a design file and a testbench file.
